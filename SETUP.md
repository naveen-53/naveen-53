# GitHub Profile Setup

Repository name must be exactly:

naveen-53

Expected structure:

naveen-53/
├── README.md
├── github-banner.gif
└── .github/
    └── workflows/
        └── snake.yml

## Important

1. Create/open the public repository `naveen-53`.
2. Upload `README.md`.
3. Upload `github-banner.gif`.
4. Create `.github/workflows/snake.yml` and paste the supplied workflow.
5. Go to:
   Settings → Actions → General → Workflow permissions
6. Select:
   Read and write permissions
7. Save.
8. Go to Actions → Generate Contribution Snake → Run workflow.
9. Wait for the workflow to finish successfully.
10. A branch named `output` should appear.
11. The output branch should contain:
    - github-contribution-grid-snake.svg
    - github-contribution-grid-snake-dark.svg

The README already uses the correct URLs for the `naveen-53/naveen-53` output branch.
